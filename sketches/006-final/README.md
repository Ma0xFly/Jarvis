## Final: 待办 + 看板 + 已完成（006）

### 信息架构
三个正交视图：
- **待办 tab**：左「今日待办」右「待办仓库」，两个列表，左右互拖分配，栏内拖动排序。
- **看板 tab**：独立流程视图，7 列（待整理 / 待执行 / 就绪 / 运行中 / 待拍板 / 待验收 / 已完成），拖卡片 = 改状态。
- **已完成 tab**：历史记录，按今天/昨天/更早分组，悬停可「恢复」。

### 交互
- 勾选完成 → 任务从待办池消失，进入「已完成」tab，看板落到已完成列（划线+淡化）。
- 「恢复」→ 回到它原来的池子（今日或仓库），状态重置为待执行。
- 新建：仅侧栏按钮（顶栏按钮已按需求移除），弹窗含「同时加入今日待办」「AI 补全任务书」。
- 主题：CSS 变量双主题，右上角切换，localStorage 记忆。

### 空间
窗口宽 1320，7 列完整可见（min-width 128 + flex），无横向滚动。
