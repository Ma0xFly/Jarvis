### 聚合审查发现（12 条，均带来源）

1. **Reclaim 闸门可被三个别名端点绕过** — 中间件只匹配 `POST /tasks/{id}/reclaim`；`/reassign` + `reclaim_first`、`/runs/{id}/terminate`、bulk assignee+reclaim_first 都调用同一个 `reclaim_task`，默认回 `ready`。来源：`server.py:62,1218-1225`；上游 `plugin_api.py:985-1050`、`kanban_db.py:2236-2246`；`test_dispatch.py:567-588` 只测一条。**fix now**。
2. **per-task 锁不覆盖 PATCH-ready 闸门** — `_ready_gate`/`reclaim_gate` 在 `patch_ready_gate`/`reclaim_gate` 里直接读 metadata，未取 `update_metadata`/dispatch 用的 `_task_lock`；闸门读到转发 PATCH 之间可清空验收。来源：`server.py:727,883,922,1170,1218`；`spec-1-3:100,140`。**fix now**。
3. **插件宿主与独立版闸门不一致** — 独立版 Board 拖到就绪经中间件；插件宿主 Board 直连 dashboard kanban API，无 `ReadyGateMiddleware`，空验收卡可直接进 ready。来源：`App.tsx:11-18`、`Board.tsx:124-129`、`server.py:1356`。**fix now / 架构决策**。
4. **`contract_defaults` 是“每任务一次”而非“每次派发”** — `write_snapshot` 发现已有快照即返回；卡被改回 todo/triage 后再次派发，仍沿用第一次的预算/禁区，后续 `defaults.json` 变更也到不了该卡。来源：`server.py:450-452,981`；`spec-1-2:33`；`test_dispatch.py:640-676` 只测 ready 幂等。**fix now / 定义生命周期**。
5. **Board 直接拖到就绪会创建没有快照的 ready 卡，1.4 仍给它显示“第 N 位”** — Board 的 PATCH 路径只过验收闸门、不走 dispatch；`test_dispatch.py:467-481` 明确断言直 PATCH 不写快照。来源：`Board.tsx:115-129`、`server.py:1169-1183`、`TodoPage.tsx:460-465`。**fix now**。
6. **metadata 读取静默截断 200 id** — 服务端 `_parse_ids` 只取前 200，返回 200 无信号；前端 100 个分块掩盖了问题，其他调用方拿到不完整数据。来源：`server.py:1262-1270`、`test_dispatch.py:447-456`、`spec-1-2:77`。**fix now**。
7. **宿主检测有两个谓词** — `main.tsx` 只判断 `__HERMES_PLUGIN_SDK__` 是否存在，`platform.ts`/`App` 要求 `sdk.fetchJSON`；一个没有 `fetchJSON` 的 SDK 会被当成插件宿主注册，却渲染待办并发 `/api/workbench/*` 404。来源：`main.tsx:7-14` vs `platform.ts:25,70`。**fix now**。
8. **幂等建卡重试会重置验收/契约编辑** — 同一 idempotency key 重试时，服务端在 triage 校验后无条件 merge 初始空契约，覆盖用户在两次尝试之间补的验收。来源：`server.py:863-871`、`test_todo.py:227-236`。**fix now**。
9. **首次加载在 metadata 到达前就清除 loading** — `setLoaded(true)` 在 `getTaskMetadata` await 之前，首帧会渲染空的今日/长期与“未写验收”。来源：`TodoPage.tsx:162` vs `:168`；探针等待 repo 卡后才断言，观察不到该窗口。**fix now**。
10. **一次挂起的 dispatch 会永久卡住待办页** — `dispatchTask`/`plainFetch` 没有 timeout/abort，`dispatchInFlightRef` 只在 finally 清理；请求不返回时 pending 回执常驻、后续 drop 全是“正在派发上一张”。来源：`TodoPage.tsx:98,226-244`、`platform.ts:39-68`；`spec-1-2:218,239` 已记录线程池自锁风险。**fix now**。
11. **Board 泄露英文闸门码** — Board catch 显示 `e.message`，即 `missing_acceptance`；Todo 同场景显示中文抖动提示。来源：`Board.tsx:132-134`、`platform.ts:48-63`、`server.py:748`。**fix now**。
12. **验证资产不触碰上述边界** — 探针只跑独立版，从不拖 Board；后端只测 `/reclaim`、ready 幂等；没有插件宿主 SDK stub、没有闸门锁竞态、没有 rework 后再派发。来源：`todo-probe.mjs:293-302,1519-1522`、`test_dispatch.py:567-588,640-676`、`test_todo.py:689-811`。**fix now（补边界测试）**。

## Fix follow-up (2026-11-05)
